mechanistic interpretability

神经网络本来就是干净的
——Goodfire 联创推翻 superposition 经典证据

Nick Cammarata · Goodfire · already-clean.goodfire.com · 65 min read
一句话：让整个领域相信"网络是乱结"的经典证据，全部被误读。所谓 polysemanticity 大多不是 superposition，而是一个可修的学习问题 + 一个他命名为 recursive generalization 的图案。神经网络本来就是干净的——可以直接研究，不需要先解开。

Nick Cammarata 是谁？Goodfire 联合创始人，mech interp 奠基论文 Zoom In 的作者之一——领域里那条最著名的"车散进狗神经元"电路，就是他和 Chris Olah 在 2019 年找到的。现在，他亲手把这块奠基石拆了。

一个奠基者拆自己的地基

mech interp 的起点是一批"多义神经元"：InceptionV1 一个神经元同时响应猫脸和汽车前脸；末层几乎找不到可解释的神经元。主流解释是 superposition——神经元不够用时，网络把不相关概念折叠进同一神经元，因为它们互不冲突。网络从此被当成一团结：要先解开才能研究。SAE 这条十年路线，就是造一台"解结机"。

Cammarata 的反转：superposition 应该是排最后的假设，而不是默认假设。它最激进、最难检验——而且他回查原始证据后发现，经典证据根本站不住。

InceptionV1 末层：架构烂，不是网络脏

决定性实验：同样的参数量、同样的数据，换成现代架构（残差连接 + LayerNorm + 合理正则）重训出 ConvNeXt，末层 99-100% 的神经元轻松可读，而且在 300 倍参数范围内全部成立。模型小的时候神经元只是变粗（一个神经元管多种车），并不会折叠不相关的东西。

混乱不是"第二种学习原理"，就是普通的学习失败，还好修。更扎心的细节：特征可视化在深层会 reward hacking，当年看到的"乱"，一部分是显微镜的问题，不是标本的问题。

InceptionV1 末层——当年让整个领域相信"网络是结"的经典证据。如今回看：工具的 reward hacking + 架构缺陷的叠加。

recursive generalization：真正发生的图案

那混乱的神经元当年在干什么？他重训模型全程围观了一个神经元的诞生：从黄花田起家，沿照片的每个侧面发芽——向其他自然物、向绿色的球、向没有花的狗。这个模式叫 recursive generalization：神经元先在一个轴上泛化，再沿别的轴分叉，每一步局部都跟得通，只是终点不再 monosemantic。

语言模型里遍地都是："iy" 神经元从 Miyazaki 长到 diy，再长到 do it yourself——已经没有 "iy" 了；地质学神经元长进了 Cesium，一个地质学 JavaScript 库。他 2021 年在 Multimodal Neurons 里就见过这模式（叫 conjoined features），只是没人——包括他自己——想到这就是全称解释。

泛化和 superposition 的预测正好相反：泛化是局部的（垂耳狗神经元装各种角度的垂耳），superposition 是非局部的（垂耳狗 + 拉丁诗歌）。他看过几百个"任意混合"，每次深挖都是语义：一个 "pr" 神经元顶部混着 Base64 URL 和孟加拉语，解码之后——全是 "pr"。

SAE 检验：没找到神经元之外的构件

如果组合神经元真在藏东西，字典就该找到神经元缺失的构件。他把 SAE 训到这些层上，人肉加 agent 翻了个遍：末层 SAE 88% 的活动是单个神经元的近似拷贝；删掉所有不对应任何神经元的字典方向，准确率不变。他的比喻很妙：SAE 单元是"不同场景里的蜘蛛"，神经元是"腿的图案和网"——字典没发现任何根本性的新积木。

弱激活、稀有物、对抗样本：都不在暗处

把全网弱激活几乎全切掉，几乎无代价——关键的东西没藏在弱激活里。稀有类别反而更合并：狗需要一大堆图案，三角龙一个神经元就够。教模型"伞的照片 = 蜜蜂"，九步之后模型走的是已有的蜜蜂线路，没有另起炉灶造私藏特征。顺藤摸瓜查对抗样本，走的也是正常语义线路。记忆这东西倾向于贴着输出坐——查表就行，不必藏。

对做安全的人这条值得划线：审计时看到"异常混合"，先怀疑工具、解释和架构，最后才怀疑隐藏打包。排查顺序错了，方向就全错。
同一参数量、同一数据下的 ConvNeXt 末层神经元：4 个神经元各自 50,000 张图中的 Top-20 响应——干净、单一职责。

语言模型：万亿参数也是同一个故事

Qwen3-32B 逐神经元研究，Kimi K3 上做出已知首张万亿参数模型的 attribution graph（模型捡到钱包，电路通向 lost property 和诚实，回答"归还"）。随机抽 1000 份神经元详细调查：约 90% 的神经元基本只有一个工作，剩下的大多两三个相关职责——他从没见过一个神经元干十件不相关的事。

顺手抓到一个架构 bug：SwiGLU 的 gate 和 value 同时为负时，激活会回声到正极，4% 神经元的顶部激活全是回声。原话送给架构设计师："we think you should look into fixing this"。MoE 专家比文献报道的特化得多，而且天然 anti-superposition——router 只是一个小线性层，养不起装了一万种东西的打包专家。

枚举式 vs 探索式

他把领域分成两种风格。枚举式：先拿一份大特征清单审计，怕漏掉什么。探索式：带着问题进去，像 Google Maps 一样在 attribution graph、神经元、attention 之间自由缩放。他押后者：如果能按按钮让所有神经元完美 monosemantic，或者换"理解清楚几个真正关心的问题的电路 motif"，他一秒选后者。"特征是否多于维度"基本无关紧要，连定义 feature 这个老大难都可以绕开。

网络为什么长成这样？因为这样学习更快：有了汽车区，再加一辆边际成本最低。部件是为下游读者建造的——解释性的目标不是给网络整形，而是 become another reader，用网络自己读者的方式读它。

点评：路线判决，不只是观点

三个理由值得全文精读。一，作者就是奠基证据的当事人，自我纠错比外人挑刺值钱得多，而且他明说：此后没有任何人在真实网络里发表过第二个该形状的电路。二，如果成立，SAE 十年军备竞赛是给一个不存在的问题造显微镜——不是没用，是优先级排错了；他不是要砸 SAE 的饭碗，是把"先解开再研究"的预设撤了。三，对安全审计是根本性利好：审计对象不需要先被解开，可解释性从"几乎不可能的任务"降维成"很多小修小补"，而自动化科学家（agents）刚好能在几个月里跑完人类十年的路。

冷静的一面也要说：这是 working hypothesis 不是论文，没有同行评审，细节支撑在即将发布的技术论文里；attention 还没啃动；Goodfire 的商业路线恰好就是 neuron-native 审计，有利益相关。但一个十年路线的亲历者，用八个月亲手复查原始证据后反水——这个信号本身，就值得你花掉那 65 分钟。
