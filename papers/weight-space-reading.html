不跑一次推理，模型能预判改权重的后果吗？

Weight-Space Reading：测的不是"模型能不能改权重"，而是"怎么测才不会骗到自己"。三个反直觉发现，比主结果更有价值。

Şuayp Talha Kocabay（Poindexter Labs）· 2026 年 11 月 · 代码与 harness：github.com/suayptalha/wsr

上个月解读的 Weight-Space Programming（Takehi et al.）演示了一件事：一个 frontier 模型能从一个小网络的原始权重里认出它被训练来玩什么游戏，还能不动梯度、直接改权重修复一个小语言模型。抓眼球的动作是"写"。但写的另一半是读——动刀之前，能不能预测这次改动会带来什么行为后果？Poindexter Labs 的这篇《Weight-Space Reading》把"读"单独拎出来，用预注册协议做了一次严格测量。

先给结论：能。但它顺带证明了，这个问题稍不留神就会测错——而且错法是可预测的。

§1实验设计：无 GPU、无前向、只有张量

Reader agent 关在只有 CPU 的沙箱里，拿到目标模型的权重文件和一套 Python/NumPy 工具，不给任何前向推理。它要回答的问题是：对模型做一次手术式编辑——缩放某层的输出投影、改 embedding 里某个 token 的行、去掉 unembedding 里的某个方向、注入范数匹配的高斯噪声——模型的五个行为各自会上升、下降还是不变？

五个行为选得很讲究：思考长度、数学正确率（MATH 64 题）、多选正确率（MMLU-Pro 100 题）、谄媚度（48 条错误暗示题）、拒答率（StrongREJECT 60 题）。ground truth 只有一种：真去 GH200 上跑编辑后的模型，与基线种子对照后打上 ↑ / ↓ / 不变 的标签。三个目标是 Qwen3.8-27B（64 层，每四层三个 Gated DeltaNet 线性注意力块配一个全注意力块）、Qwen3.5-9B（32 层，同构）和 Muse-Glimmer-30B（52 层稠密 transformer，每个 sublayer 前后都做归一化）。

读者与目标做 2×2 交叉——27B 和 9B 互为读者和目标——这样"自读优势"才能从"读者能力强"里剥离出来。"自"在这里只是操作性定义：读者就是目标的未编辑底座 checkpoint，看到的文件和外人一模一样。对照组只给编辑的文字描述、不给权重——这是整篇论文最关键的一刀：如果看描述和看权重成绩差不多，那"读权重"就是幻觉。

§2主结果：权重确实多给了 15 个点

对非破坏性的微妙编辑，27B 读自己的权重拿到 0.730 balanced accuracy；同样的编辑只看文字描述只有 0.578。差距 +0.152，95% 置信区间 [+0.056, +0.256]，不含零。四个"读者–目标"对里三个是权重占优。

条件（Subtle 轮 · 非破坏性编辑）Balanced Acc变化召回
27B→27B · 权重 + Python 工具0.7300.667
27B→27B · 仅文字描述0.5780.278

变化召回 = 真正发生的行为变化中被读者抓到的比例：看权重约三分之二，看描述约四分之一。

更直观的是变化召回：看描述只能抓到约四分之一真正发生的变化，看权重能抓到三分之二。模型确实从张量里读出了描述里没有的信息——零样本，没训练过，没跑一次前向。这直接回应了 Ahmed 对 WSP 的质疑（"那可能只是记忆模式的检索"）：至少对"读"的一半，有真实的分析成分。

§3然后是三个冷发现

冷发现一：自读没有优势

交叉对比的设计初衷是检验"模型对自己的权重是否读得更准"。把读者能力和目标难度做加法抵消后，crossed contrast 在每一轮都为正，但置信区间全部包含零。更扎心的是跨家族对照：Muse-30B 读自己的权重只有 0.468，而 27B 这个外人来读同样的权重拿到 0.615（差值 95% CI [+0.027, +0.258]）。

读者 → 目标Balanced Acc说明
27B → 27B0.593破坏性编辑（Full-Dose）
Muse-30B → 27B0.594异家族读者打平本体
27B → Muse-30B0.615外人比本体读得好
Muse-30B → Muse-30B0.468自读反而最差

解读只有一句话：读权重是一种通用分析能力，不是自我内省。谁的功力深，谁读得准，跟"是不是自己的脑子"关系不大。这与 self-knowledge 文献的近期走势一致——Ferrara 用 d′ 和 AUROC 检验激活层干预的自我觉察，结论同样是"不比随机好"。

冷发现二：读者发现不了编辑什么都没做

全篇最有警示价值的发现。Muse-30B 每个 sublayer 前后都做归一化，所以均匀缩放输出投影在数学上就是无效操作——40 个编辑（34 个标准编辑 + 6 个 no-op 对照）实测全部没有改变任何行为。但拿到权重的读者照样有 53%–88% 的编辑被预判"会有变化"；Muse-30B 自读自己的权重时，85% 的编辑被它声称有效。

读者从不怀疑"这次编辑可能什么都没干"。它看到了张量的变化，就默认行为会变——没有任何读者去验证架构会不会把这次编辑整个吃掉。

冷发现三：破坏性编辑测的是损毁检测

全强度编辑大多直接把模型打进死循环或崩掉识别能力。这种编辑上，异家族的 Muse-30B 读 27B 的成绩（0.594）和 27B 自读（0.593）打平。也就是说，如果你的 benchmark 全是破坏性编辑，你测到的只是"任何能干的读者都能看出这网络坏了"——跟读权重的能力没关系。测试"读"，必须用保留生成质量的非破坏性编辑，而这种编辑恰恰最难造：27B 上 94 个候选编辑只筛出 10 个真正有效且不破坏生成的。

§4四条评估军规

作者把三次差点得出错误结论的教训收拢成四条，值得任何做这类评测的人抄在墙上：

破坏性编辑测的是 damage detection。任何能干的读者都能看出灾难性扰动毁了一个模型。读力的检验必须建立在生成质量尚存的非破坏性编辑上。
基率可以双向作弊。原始 accuracy 奖励永远答"不变"，召回率单独用则奖励永远答"变了"。必须用 balanced accuracy 或 threshold-free 指标。
"会不会变"很大程度写在描述里。读者置信度做 threshold-free 打分，看权重的 AUROC 中位数 0.76，仅看文字描述也有 0.73。权重真正贡献的是变化的方向——评估应该只给描述给不出的部分记分。
编辑必须尊重架构。在归一化层之后的输出投影上做均匀缩放就是 no-op。为一个架构设计的干预库，在另一个架构上可能无声失效。

§5代价与局限

ground truth 贵得离谱：三轮共 475 次全量评估（460 个编辑后 checkpoint + 15 个基线种子运行），每次对 288 个条目做思考模式生成、上限 8192 token——共 136,800 次生成、约 5 亿 token，全部跑在 GH200 上。这解释了为什么每个格子只跑一次、没有运行方差估计，也解释了为什么多重比较未做校正——论文自己承认 bootstrap 区间偏乐观。非破坏性有效编辑的稀缺（94 选 10）让 Subtle 轮的统计底座很薄。另外 Text-Only 基线用整数 ID 标识词表行，可能天然吃亏；自读对比只有一对模型，加性假设只是近似成立。作者把这些全部摊开写进了 Limitations——这份诚实的代价清单本身也是论文的一部分。

§6把三篇论文连起来读

WSP（写）与 WSR（读）是一对：前篇证明 frontier 模型能写入权重改变行为，本篇测量写入之前的"效果预判"有多可靠。两半合起来才是完整的 weight-space programming 闭环——而预注册、交叉设计、no-op 对照这套测量基础设施，恰恰是前篇缺的那一块。

introspection 文献（Binder 的自我行为预测、Lindsey 的概念向量注入、Ferrara 的 sham-intervention 检验）从激活层走向权重层，结论方向一致：模型对"自己"并没有特权视角。自我觉察如果存在，目前还没被任何干净的测量捕捉到。

与 CORTEX 的连线 前几天解读的 Cortex 主张把上下文"买断"成参数记忆——把信息直接写进权重。这类参数级写入想走向生产，前置条件就是"读"可信：写入前的编辑效果预测、写入后的行为审计，正是 WSR 定义的任务。Cortex 管怎么写，WSR 管写了之后怎么知道写对了。两条线合流的地方，才是可审计的权重级 agent 记忆。

§7结语

表面上这篇论文在回答一个能力问题，实际上它在示范一种态度：能力声明和测量是两件事，后者难得多，而且错法是可预测的——基准用破坏性编辑就测成损毁检测，指标忽略基率就奖励常数答案，干预库不尊重架构就无声失效。对做 agent 自改权重的人，"编辑效果预测"是写入安全审计的第一道闸；对做评测的人，这篇论文是"预注册 + 交叉设计 + 阴性对照"的教科书。作者把 harness 开源了（github.com/suayptalha/wsr），这个领域接下来比拼的不是谁的模型更强，而是谁的测量更干净。
