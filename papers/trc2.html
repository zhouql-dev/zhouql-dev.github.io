Efficient Continual Learning in Language Models via Thalamically Routed Cortical Columns
Afshin Khadangi · arXiv 2602.22479 (v6)
一句话：持续学习的正确抽象不是"更好的更新规则"，而是"把可塑性关进笼子"——快通路负责学，慢通路负责记，中间隔一个只传调制信号的丘脑。TRC² 在 22k 步三任务流上把累计遗忘（PPL AUFC）压到 0.44，基线族普遍 1.1–1.6；代价是约三分之一的吞吐。

大模型部署之后世界不会停下来等你。语料在变、用户行为在变、任务组合在变，但模型要么定期全量重训，要么靠 LoRA 这类轻量更新——后者跑长了照样互相干扰，学新的忘旧的，这就是灾难性遗忘。现有的缓解手段（回放、正则、参数隔离）几乎都是"外挂"：在基本不动的骨架外面加流程、加约束。这篇论文的立场很直接：持续学习应该是骨架本身的属性，不是训练技巧。

于是作者造了一个相当"生物"的东西：TRC²，Thalamically Routed Cortical Columns，丘脑路由皮层柱。名字听着像神经科学综述，实际是一个 decoder-only 架构，把三个子系统焊进了主干。

三件套：柱、丘脑、海马体

皮层柱堆叠。每一层就是一个"柱"：RMSNorm + 注意力 + 路由 SwiGLU MoE，老配方。但柱与柱之间不是简单串行，而是由丘脑路由器居中调度。前 2/3 的柱构成"早皮层"，后 1/3 构成"晚皮层"。

丘脑通路。丘脑在大脑里是皮层间的中继站和增益调节器。论文里，每根柱把中间状态投影出去（类比皮层 V 层到丘脑的投射），路由器压缩后走两条路：一条局部门控通路，一条由严格过去均值驱动的"弥散"通路，再经 TRN 式竞争抑制防止过度激活，最后只调制下一根柱的 query 流——K 和 V 完全不动。这是个很克制的设计：信息只通过"往哪看"（query）注入，不直接改写"看什么"。

海马体。负责情景记忆的存取和回放，四个设计值得单独说：

① 读路径严格因果：当前前向只读"过去写入"的记忆，读不到本次正在写的内容；
② 写路径延迟：前向只攒 pending 候选，反向传播完成后才按"惊讶度"（慢速 TD 残差）筛 top-k 写入环形缓冲——先读后写，时序不穿越；
③ 回放永不碰当前 batch：replay 样本在当前 batch 插入前采样；
④ 在线回放控制器：PI 规则实时监测已见任务的遗忘量（log-PPL 空间），遗忘大就调大回放强度、批量、长期库采样比例，遗忘小就松开。

这个"测遗忘 → 调回放"的闭环是全文最工程化的亮点。多数回放方法的回放强度是拍脑袋定的超参，这里是自反馈的。作者还做了一组精确验证实验（克隆扰动测试），确认主 logits 路径严格自回归、写入分数因果、梯度累积下写语义正确、评测调用不重置记忆——把"因果纪律"当成可验证的工程性质来交付，这在同类论文里少见。

结果：边界更强，忘得更少

任务流 C4 → WikiText-103 → GSM8K，共 22k 步，4×V100 单机，对比 Transformer、Mamba、MoE、DeepSeekMoE、BlkAttnRes、FALCON、LoRA-DRS 七个基线族，3 seeds。任务边界 PPL 全面占优：560M 的 TRC² 在 C4 上 33.49，同规模最好的 Transformer 基线 76.27；GSM8K 上 29.87 对基线的数千——低两个数量级。更重要的是遗忘：

PPL AUFC（累计遗忘面积）0.44，基线族普遍在 1.1–1.6——遗忘减半还多。顺序鲁棒性实验把三个任务顺序打乱重跑五种排列，TRC² 依然在最低遗忘带，且方差比基线小得多：优势是架构性的，不是这条任务序列的运气。

消融：终点最好 ≠ 保留最好

拆掉丘脑+海马体，末端指标反而更好——最后一个任务的 PPL 26.79 vs 全模型 31.28，吞吐从 103k 涨到 154k tokens/s——但 AUFC 从 0.44 恶化到 0.78。只拆海马体掉得最狠（0.76），说明记忆存取是保留能力的主力；只拆丘脑掉得温和（0.56）。

最强的终点检查点 ≠ 最强的持续学习方案。这句话值得所有刷榜单的人贴在工位上。

系统成本是诚实的：多了路由、检索、回放，绝对最快的配置仍是稠密基线（154k vs 103k tokens/s）。但 d768-l4（226M）恰好落在效率前沿的好位置——边界质量强、吞吐反超多数基线、显存×时间全场最低（134 GB·h）。代价真实存在，但不是不可接受。

三点判断

一，"生物隐喻"是结构性的，不是装饰性的。丘脑=调制通路（只动 query），海马=写延迟+回放+巩固，每个部件都有明确的计算职责。但要说清楚：它不是"类脑模型"，是把两条神经通路的功能需求翻译成了可训练的模块。类比在架构层就结束了，没有延伸到学习算法层。

二，规模天花板明确。所有实验在 560M 以下、4×V100 量级完成；GSM8K 用 teacher-forced token accuracy 而非解题率（作者自己声明了）。放大到 7B、70B 还是"低遗忘"吗？没人知道。但反过来说，持续学习最痛的场景恰恰是中小模型频繁更新——端侧、垂直域、私有部署。这个规模的验证有现实意义。

三，对 agent 记忆系统是份可直接抄的设计清单。事件选择性写入（只存高惊讶状态）、先读后写的因果纪律、用测得的遗忘量反向调节巩固强度——这三条跟具体架构无关，搬到任何 memory 系统上都成立。
